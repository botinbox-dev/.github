### What you can build

- **Support agents** that answer customers by email and escalate to humans
- **Sales agents** that draft outreach for a human to approve before it sends
- **QA and E2E tests** that catch sign-up and 2FA codes automatically
- **Back-office agents** for invoices, suppliers and scheduling

### Connect in one line

```sh
# Remote MCP server for Claude Code, Cursor and other MCP clients
claude mcp add --transport http botinbox https://botinbox.dev/mcp \
  --header "Authorization: Bearer $BOTINBOX_API_KEY"

# Or the CLI
brew install botinbox-dev/tap/botinbox
```
